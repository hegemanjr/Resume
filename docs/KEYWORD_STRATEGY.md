# Keyword & Versioning Strategy

## Core Skill Set (Present in all versions)

*
**PHP (15+ years):** PHP 8.2, Rector, PHPStan, PHPCS.


*
**Architecture:** WordPress Multisite (130+ sites), high-availability ecosystems.


*
**DevOps/Infrastructure:** Lando, Docker, WSL2, Proxmox.



## Version 1: Senior Software Engineer (The "Main" Resume)

* **Target:** High-level development and platform engineering roles.
*
**Emphasis:** Code integrity (PHPStan), automated refactoring (Rector), and standardizing developer environments (Lando/WSL2).


*
**Keywords:** Platform Engineering, Quality Governance, Automated Modernization.



## Version 2: Systems Architect / SRE

* **Target:** Roles focused on infrastructure, automation, and reliability.
*
**Emphasis:** High-availability Proxmox laboratories, secure mesh networking (Tailscale), and mission-critical hardening.


*
**Keywords:** Hypervisor Management, Network Security, Strategic FinTech Automation, Infrastructure Automation.



## Version 3: Technical Lead / Manager

* **Target:** Management or lead roles where oversight is key.
*
**Emphasis:** Managing 130+ production sites, leading manual and automated source code upgrades, and architectural oversight of multi-million dollar account structures.


*
**Keywords:** Strategic Automation, Lifecycle Management, Architectural Oversight.
