# Styling & Design System

## Philosophy: Chemical Minimalism

To ensure the highest contrast and professional legibility, we avoid bloated layouts and "over-seasoning" the Eisvogel template.

## Design Decisions

* **Title Page:** Disabled (`titlepage: false`). We prioritize getting the "Technical Craftsmanship" details (including the Musgrave Rule quote) on the first page immediately.


* **Backgrounds:** Removed. Pure white backgrounds ensure maximum compatibility across different PDF readers and physical printers.
* **Colors:** Default high-contrast black text on white.
*
**Header/Footer:** Configured to include name and page numbers for multi-page document integrity.



## Template Overrides

* **Eisvogel Modifications:** Any future adjustments to the `.tex` file regarding font size or margin density should be noted here to prevent breaking the "Documentation as Code" flow.
