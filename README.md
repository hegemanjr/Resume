# Engineering-First Resume

This repository houses my professional history, maintained in Markdown to ensure
version control, portability, and a "documentation-as-code" approach.

### Why Markdown?

As a Linux daily driver and advocate for open-source workflows, I believe a
resume should be as maintainable and transparent as the code I write.

### Principles

* **The Musgrave Rule:** A commitment to craftsmanship. Doing it right the first
  time is the only way to move fast in the long run.
* **Platform Reliability:** My background isn't just in writing features; it's
  in building the infrastructure that makes those features possible.
